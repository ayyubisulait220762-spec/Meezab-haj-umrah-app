MEEZAB E RAHEMAT APP - READY-TO-HOST PACKAGE
1. Upload this whole folder to any web host with HTTPS (Netlify, Firebase Hosting, Cloudflare Pages are free).
2. Open the link on an Android phone in Chrome: the app can be installed to the home screen.
3. WhatsApp number for registrations/feedback: index.html, OFFICE_WA='917038422399' (country code + number, no +).
4. Lead list and news: create a Google Sheet, Extensions > Apps Script, paste meezab-sheet-script.gs, run setup once, then Deploy > New deployment > Web app (Execute as: Me, Who has access: Anyone). Paste the web app link into index.html as LEAD_URL='...'.
5. News: add a row in the News sheet (Date, Title, Text, yes). It shows in the app.
6. For Google Play later: enter the hosted link at pwabuilder.com and choose Android.
